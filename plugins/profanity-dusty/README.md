# profanity-dusty

Dusty Jones — in-house copywriter for Profanity Creative.

Dusty writes studio copy, long-form content, client brand copy, and gives honest editorial feedback. He knows the outdoor and lifestyle space from the inside, writes like a human being, and will tell you when something sounds like it was written by a marketing department. He also handles SEO — auditing content, recommending keywords, and making sure the work gets found without compromising the voice.

---

## Components

### Skill — `dusty-jones`
Loads the full Dusty Jones persona, Profanity's voice principles, and the five-mode system. Triggers automatically on any copy-related or SEO request.

### Commands

| Command | What it does |
|---------|-------------|
| `/write` | General-purpose. Describe what you need — Dusty figures out the right mode. |
| `/studio-copy` | Copy for Profanity's owned channels: website, bio, about page, case studies, capabilities deck. |
| `/write-content` | Long-form content in Mark's voice: blog posts, process pieces, perspective pieces. |
| `/brand-copy` | Copy for a client brand in their voice. Gathers brief, delivers two angles. |
| `/edit-voice` | Honest editorial feedback on existing copy — what's working, what's not, and a revised version. |
| `/seo-audit` | SEO audit for any piece of content — title tags, meta descriptions, keyword placement, quick wins. |

### MCP Connections
- **Notion** — save drafts, pull project briefs, build a copy library
- **Gmail** — read client emails for context before writing client brand copy

---

## Usage

**Quick write**: Use `/write` with a short description of what you need. Dusty will ask one clarifying question if needed, then get to work.

**Focused modes**: Use the specific commands when you know what you need:
- `/studio-copy about page` — write or rewrite the Profanity about page
- `/write-content the brief I got last week from Burton` — pull that email and write a piece
- `/brand-copy [brand name]` — start the client brief intake flow
- `/edit-voice [paste your copy]` — get honest feedback and a fixed version

**Notion workflow**: After any writing session, Dusty will offer to save the draft to Notion. Say yes and point him to the right page or database.

**Client context from Gmail**: For client brand copy, Dusty can search your Gmail for past emails from the brand to pull tone references, briefs, or background before writing.
