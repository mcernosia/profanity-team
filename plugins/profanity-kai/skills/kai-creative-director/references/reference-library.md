# Reference Library — directors, photographers, studios

A starting library to anchor visual direction. Use as a starting set — augment per project.

## Outdoor / action sports filmmakers
- Anthill Films, Sherpas Cinema, Camp 4 Collective — long-form action sports cinematography.
- The Public House — outdoor brand work.
- Stept Studios — lifestyle / outdoor brand mix.

## Product / DTC viz studios to study
- Territory Studio — UI/screen graphics + product work.
- Buck — premium motion + product launches.
- ManvsMachine — bold typographic + product motion.
- The Mill — high-end visual effects + product.

## Photographers
- Chris Burkard — outdoor/landscape, cool palette.
- Cory Richards — adventure/expedition.
- Lucas Gilman — action sports.

## Color / palette anchors
- "Burnt earth" (not "modern rustic"): muted ochre + cool shadow.
- "Cold morning" (not "soft light"): blue ambient + warm key.
- Build palettes from real-world objects: "the orange inside a split blood orange," not "vibrant orange."

Expand this list as projects bring new references in.
