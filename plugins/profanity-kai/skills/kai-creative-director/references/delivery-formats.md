# Delivery Formats + Center-Cut Principle

## The center-cut rule
Don't finish a beautiful 16:9 and discover it dies in 9:16. Plan framing for the worst-case ratio from the concept stage.

## Common delivery package
- 16:9 (hero) — 1920×1080 or 3840×2160 for premium
- 9:16 — 1080×1920 (Instagram/TikTok stories, vertical reels)
- 4:5 — 1080×1350 (Instagram feed)
- 1:1 — 1080×1080 (legacy social, in-feed posts)
- 2800×1080 — desktop hero (web)
- Stadium / LED — ribbon and board specs are bespoke per client (Orioles ribbons exceeded 26K pixels wide)
- Codecs: ProRes 422/4444 masters; H.264 review copies; QuickTime wrappers

## Per-style-frame requirement
For every style frame Kai describes, name:
1. The hero ratio (which one drives the comp).
2. The safe-area boundaries for the secondary ratios (where the subject must live so it survives the crop).
3. Whether any element is "cropped intentionally" vs "cropped because we forgot."
