# Expense Categories — Profanity Creative

Standard QuickBooks categorization for a one-person 3D studio. CPA confirms the actual chart of accounts at filing time, but these are the working buckets James uses when reviewing transactions.

## Income Categories

| Category | What goes here |
|----------|----------------|
| **Service Revenue — Direct Client** | Project invoices paid by brand/end client |
| **Service Revenue — Agency / Production Co.** | Subcontracted work through an agency or production partner |
| **Service Revenue — Day Rate / Freelance** | Hourly or daily freelance work outside a fixed-scope project |
| **Refunds / Adjustments** | Client refunds, credits issued |

## Cost of Goods Sold (Project-Direct)

These are costs directly attributable to a specific client project. Critical for project profitability math.

| Category | What goes here |
|----------|----------------|
| **Contract Labor / 1099** | Specialists subbed in for a specific job (animator, sound designer, rigger). Each contractor's YTD sum needs tracking for 1099 threshold. |
| **Render / Compute** | Render farm services (GarageFarm, Pixel Plow), AWS render spot, cloud GPU rental — when allocable to a project |
| **Stock / Asset Purchases** | HDRIs, textures, models, music, SFX bought for a specific project |
| **Project Software (one-off)** | Software bought specifically for one project (rare but happens) |

## Operating Expenses (Recurring / Overhead)

| Category | What goes here |
|----------|----------------|
| **Software Subscriptions** | Cinema 4D, Adobe CC, Redshift, KeyShot, Notion, Framer, Slack, Fireflies, Cowork/Claude, plug-ins. Anything monthly/annual SaaS. |
| **Render Subscriptions / Credits** | Pre-purchased render credits that aren't tied to one job |
| **Hardware / Equipment** | Computers, monitors, drives, accessories. Larger items may be depreciable — CPA decides. |
| **Office Supplies** | Small consumables, paper, pens, mailers |
| **Insurance** | Business liability, equipment, professional indemnity |
| **Professional Services** | CPA fees, legal fees, bookkeeper fees (if used) |
| **Bank Charges / Fees** | QuickBooks subscription, payment processor fees (Stripe, PayPal), wire fees |
| **Marketing & Advertising** | Vibe Prospecting, Clay, paid social, conference fees, sponsored content |
| **Travel** | Flights, hotels, mileage for business travel. Separate from meals. |
| **Meals (50%)** | Business meals — flagged at 50% deduction by IRS convention. CPA confirms. |
| **Continuing Education** | Courses, workshops, books, industry events |
| **Dues & Subscriptions (non-software)** | Industry memberships, publications |
| **Telephone / Internet** | Business-allocated portion. Sole props often allocate a % of personal bills — CPA confirms split. |
| **Home Office** | Pro-rated rent/mortgage, utilities, internet portion. CPA handles the deduction calc. |
| **Owner's Distribution** | NOT an expense (S-Corp distributions are equity movements, not P&L). Flag if it's miscategorized as an expense. Note: there is no "Owner's Draw" in S-Corp books — money to Mark is either W-2 wages (deductible payroll expense) or a distribution (not deductible). |

## Common Miscategorizations to Watch For

These come up over and over in creative-studio books — James should sweep for them.

1. **Adobe / C4D charges sitting in "Other"** → Software Subscriptions
2. **Stripe / PayPal fees lumped with revenue** → Bank Charges / Fees (gross revenue, net out fees separately)
3. **Asset packs in "Office Supplies"** → Stock / Asset Purchases (or COGS if project-attributable)
4. **CPA fees in "Other Professional"** → Professional Services
5. **Conference travel split across "Travel" and "Meals"** → Confirm meals are tagged at 50%
6. **Owner's draw showing as an expense** → Move to balance sheet (not P&L). If this is happening, the P&L is wrong.
7. **Personal Amazon / Costco charges** → Always ask Mark. In S-Corp world, personal charges paid directly from the business create constructive distributions and reasonable comp risk. Stricter than sole prop.
8. **New hardware over $2,500** → Flag to CPA — may need to be capitalized/depreciated rather than expensed (Section 179 election is the CPA's call)

## Receipts & Documentation

- IRS general rule: keep receipts for any business expense over $75
- QuickBooks should have receipt attachment for these — flag missing ones
- Subscriptions: monthly statements satisfy receipt requirement; no need to chase per-charge
- Anything over $500 should have a clear invoice or receipt regardless

## Project Tagging in QuickBooks

If Mark is using QB's class/location tagging or project tracking, every COGS-type expense should be tagged to the project it belongs to. This is what makes project profitability math possible.

If projects aren't getting tagged consistently, that's the single biggest thing standing between Mark and real margin data. Flag it as a clean-up priority.
