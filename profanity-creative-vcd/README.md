# Profanity Creative — Virtual Creative Director

A creative direction plugin for Profanity Creative, a 3D product visualization studio run by Mark Cernosia out of Vermont. Provides a fast, opinionated creative thinking partner for pre-production work: concept development, moodboard direction, style frame descriptions, and animation treatments.

Built for outdoor brands, lifestyle products, and action sports culture. The work lives between high-end commercial polish and raw, authentic texture.

---

## Components

### Skill: `virtual-creative-director`

Loads automatically when you use language like "moodboard," "style frames," "treatment," "creative direction," "let's brainstorm," or "what directions could we go." The VCD reads the context and runs the right mode without being told.

### Commands

| Command | What it does |
|---------|--------------|
| `/brief [raw notes]` | Drop a loose brief — the VCD reads it and runs the right mode automatically |
| `/concept [brand/product]` | Generate 3 distinct concept directions with full 3D direction, references, and rationale |
| `/moodboard [concept name]` | Output a structured moodboard brief with image search clusters and a "What Does NOT Belong" list |
| `/styleframe [concept/product]` | Describe 3–5 key frames at cinematographer-level specificity, build-ready for 3D |
| `/treatment [product/format]` | Write a full animation treatment with narrative arc, motion language, key moments, and reference clips |

---

## Usage

**Fastest path**: Use `/brief` with whatever you've got. Even a single sentence works:

```
/brief outdoor brand, camp stoves, rugged but premium, 15-second hero animation
```

**Direct mode**: If you know what you need, go straight there:

```
/concept ski goggle brand, something cinematic — not the usual action sports look
/moodboard Burnt Earth direction from the camp stove project
/styleframe the hero shot for the goggle campaign
/treatment 15-second product reel, 16:9, ecommerce launch
```

**Conversational**: The skill also triggers naturally mid-conversation when you use phrases like "what should the moodboard look like" or "I need some animation ideas."

---

## Output Formats

- **Concept directions** are structured for quick internal review or client presentation
- **Moodboard briefs** are formatted for direct use in Figma reference-pulling sessions
- **Style frame descriptions** are build-ready for 3D software or Figma compositing
- **Animation treatments** are formatted for Figma deck drop-in or client sharing
